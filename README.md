# 🎬 Video Editing App with Nextjs (Frontend Only)

A feature-rich, frontend-only video editing application built using **Next.js** and **React**, offering an interactive timeline-based UI with support for drag-and-drop, trimming, media overlays, and canvas rendering.

> 🚧 Note: This is a frontend-only project with no backend integration. All data is handled in-browser.

---

## ✨ Features

- Upload and preview video files
- Scene trimming and rearrangement
- Add and manipulate text/image overlays on canvas
- Responsive, modern UI built with Tailwind CSS

---

## 🛠️ Tech Stack

- **Next.js 15** – App directory support for a fast, modern React app
- **React 19** – Concurrent features and performance improvements
- **Tailwind CSS** – Utility-first styling
- **React DnD** – Drag-and-drop interactions
- **React RND** – Resizable and draggable UI overlays
- **React Dropzone** – File upload via drag-and-drop
